# Explainers Plus

Global and local explanations for tabular classifiers.

> A test plugin for the [dashAI](https://github.com/DashAISoftware/DashAI) plugin store.

## Components

| Class | Type |
| --- | --- |
| `PermutationImportancePlus` | GlobalExplainer |
| `KernelShapPlus` | LocalExplainer |

## Usage

Open a trained run and add **Permutation Importance Plus (plugin)** or **Kernel SHAP Plus (plugin)** in **Explanations**.

## Details

- **Requires:** dashAI 0.10.0 or newer.
- **Dependencies:** none.
- **Releases:** Releases are built and signed by this repo's GitHub Actions workflow (`.github/workflows/release.yaml`): dashAI shows them as verified.
